Сквозные определения и исключения

Клиент
ИНН организации. Если поля нет — ИНН физлица (892 строки, статус «Новый»/«Выдан», старые даты создания — отдел продаж). Эти 892 считаются клиентами по факту создания, отдельно от общей логики резерва партнёров.
Касса
РНМ ККТ. Один клиент → 1..N касс.
Код ОФД
PIN. Может существовать без клиента (партнёр сгенерировал впрок) и без активации.
Дата появления сущности
MIN(Дата активации) среди кодов со статусом «Зарегистрировано». Коды «Новый»/«Выдан» — резерв партнёра, в клиентские/кассовые метрики не входят. «Отозвано» — не участвует нигде, кроме отдельного счётчика.
Период
Произвольный диапазон дат («с» — «по»), один фильтр наверху. Фильтрует только виджеты с меткой период ниже — это потоковые метрики (новые/отток/реанимация и всё явно помеченное «за период»).
As-of дата
Фиксируется в момент загрузки XLSX. Не пересчитывается при открытии сайта без новой загрузки. Виджеты с меткой as-of — снэпшот текущего состояния, верхний фильтр периода на них не влияет.
Отток
Считается раздельно по клиентам и по кассам — два независимых показателя, не объединяются. Касса: «Общая дата окончания» попадает в [начало периода; конец периода] (не только «раньше конца» — иначе считает накопительный отток за всё время вместо оттока именно за выбранный период), и к as-of дате продления не было. Клиент: в оттоке, когда в оттоке абсолютно все его кассы.
Реанимация
Сущность была в оттоке на конец периода, но появилась новая дата активации в окне [конец периода; конец периода + 3 мес].
Продления кассы
Не полагаемся на флаг «Тип активации» (в 298 цепочках из 263 675 встречается два «Первичная» подряд — флаг иногда врёт). Считаем так: берём только коды со статусом «Зарегистрировано» (отозванные из цепочки исключаются — по правилу выше «Отозвано» не участвует нигде, кроме своего счётчика), сортируем по дате, число продлений = количество оставшихся кодов − 1.
B1 / КЛИЕНТЫ

Клиенты

Всё на уровне ИНН, агрегировано по всей базе — не карточка одного клиента.

Активные клиенты сейчас

карточкаas-of

Счётчик уникальных ИНН, у кого хотя бы одна касса не в оттоке на as-of дату. Снэпшот — верхний фильтр периода на это число не влияет.

Новые клиенты за период

карточка + графикпериод

Дата появления ИНН попала в выбранный диапазон. График — помесячно внутри диапазона.

Отток клиентов за период

карточка + графикпериод

ИНН, у которых все кассы вышли в отток внутри периода (см. определение оттока выше).

Реанимированные клиенты

карточка + графикпериод

Были в оттоке на конец периода, вернулись в окне +3 месяца.

Нетто-прирост базы

графикпериод

Новые минус отток, накопительный итог по месяцам периода.

нетто(t) = новые(t) − отток(t)
накопительно(t) = накопительно(t−1) + нетто(t)

Распределение по числу касс

графикas-of

Гистограмма по всей базе клиентов: 1 / 2–3 / 4–9 / 10+ касс на ИНН. Снэпшот на as-of.

Клиенты «под риском»

таблицаas-of

Клиенты, у которых общий срок ближайшей кассы подходит к концу — считается от as-of, не от верхнего периода. Переключатель — только одно из двух полей активно за раз.

Счётчик РНМ, чья «Общая дата окончания» ≥ as-of дата. Снэпшот, период не влияет.

B3 / ПАРТНЁРЫ

Партнёры

Таблицы и счётчики по всем партнёрам сразу — без карточки одного партнёра.

Действующие партнёры сейчас

карточкаas-of

Партнёр = есть хотя бы 1 активная касса или клиент на as-of дату. Снэпшот, период не влияет.

таблицаas-of

1 строка на партнёра: число закреплённых клиентов (партнёр = последний по дате активации), число касс, число неактивированных кодов в резерве. Сортируемая целиком, снэпшот на as-of.

B4 / КОДЫ ОФД

Коды ОФД

Учёт кодов вне привязки к клиенту — воронка, резерв, аннулированные.

Неактивированные коды по годам

график, раскрываетсяas-of

Клик на год → раскрытие по месяцам. Считаются коды, созданные и не активированные к as-of дате. Весь срез разом, верхний период на выбор года/месяца не влияет.

Неактивированные коды по партнёрам

таблица, раскрываетсяas-of

Топ-список партнёров по резерву. Клик на партнёра → раскрытие год + месяц (при необходимости — до дня). Снэпшот на as-of.

Отозванные коды

карточкапериод

Отдельный счётчик за период. Больше нигде не учитывается — ни в оттоке, ни в резерве, ни в базе клиентов/касс.

Общая воронка

графикпериод

Создано → активировано → зарегистрировано / отозвано, для кодов, созданных в выбранном периоде. Плюс среднее время от создания до активации.

Доля кодов «впрок»

карточкапериод

Доля кодов, сгенерированных партнёром без клиента на момент выгрузки, от всех созданных за период.

Механика сайта

  1. ЗагрузкаПеретащить XLSX в браузер или выбрать файл. Обработка — целиком на клиенте, ничего не уходит на сервер.
  2. ПересчётAs-of дата фиксируется на момент загрузки. Все борды и виджеты пересчитываются от неё.
  3. ПериодОдин общий фильтр «с — по» наверху — фильтрует виджеты с меткой «период». Виджеты с меткой «as-of» игнорируют его и всегда показывают снэпшот на дату загрузки.
  4. Библиотека виджетовПравая панель — все ~25 виджетов из B1–B4, сгруппированные по бордам.
  5. Drag-and-dropПеретаскивание виджета из библиотеки на рабочую область. Свободная сетка, можно сопоставлять виджеты из разных бордов рядом.
  6. ЭкспортУ каждой таблицы — кнопка «Экспорт CSV / Excel», отдаёт чистый список данных.
